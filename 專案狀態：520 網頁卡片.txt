目前完成的功能
════════════════════════════════

【開場場景】
  - 點信封打開 → 背景從深紫轉粉色 → 顯示「520」大字 + Kirby 動圖 + 出發按鈕
  - 開場裝飾：3 隻 Kirby（pk-walk / pk-bounce / pk-walk），每隻 76×76px

【角色】
  - 主角改為 Kirby GIF（kirby-runningpress-start-final.gif）
  - 地圖上 Kirby：72×72px，走路時上下浮動動畫（無旋轉）
  - face-left class 用 scaleX(-1) 鏡像翻轉，向左走自動翻面
  - JS 座標偏移：px = x% * vw - 36，py = y% * vh - 72

【地圖主場景】
  - 9 個節點（index 0~8），SVG 貝茲曲線路徑，虛線棕色小徑
  - 順序解鎖：只能點下一個停留點（pulsing 金色動畫提示）
  - 長花機制：點下停留點沿路徑長花（粉花 emoji，路徑花 + 停留花）
  - 左上進度條：「停留點 X / 8」（共 8 個可走停靠點）

【底部卡片 - 相片/影片】
  - 支援多張照片：photos 陣列，點擊相框切換下一張
  - 底部圓點指示目前第幾張（粉色圓點，當前用桃紅色）
  - 右下角「點擊換張 →」提示（多張時才顯示）
  - 支援影片（.mp4 / .mov / .webm）：黑底 contain 顯示，內建播放器
  - 切換/關閉時自動 pause 影片
  - 支援真實圖片路徑（.jpg/.png/.webp）或 emoji 佔位符

【底部卡片 - 問答】
  - 5 題選擇題，答對/答錯即時顯示顏色 + 回饋文字
  - 進度條、最終得分訊息

【結尾】
  - 最後一個停靠點觸發全螢幕深紫結語 + 紙屑動畫
  - 3 隻 Kirby 歡慶動畫，結語文字可自訂
  - 「從頭再走一次」按鈕重置地圖

如何放到網路上（讓對方用手機看）
════════════════════════════════

方法一：Netlify Drop（最快，拖曳即上線）
  1. 開瀏覽器前往 netlify.com/drop
  2. 把整個 520card 資料夾拖進去
  3. 自動產生網址，傳給對方即可

方法二：GitHub Pages（免費，可更新）
  - 需要 GitHub 帳號
  - git init → git add . → git commit → push 到 GitHub
  - 開啟 Settings → Pages → Source: main branch
